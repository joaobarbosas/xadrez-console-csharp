# Jogo de Xadrez no Console (C#)

Projeto desenvolvido em C# como parte de um curso  
ministrado por Nelio Alves.

## 🎯 Objetivo
Aplicar conceitos fundamentais de Programação Orientada a Objetos, como:
- Encapsulamento
- Herança
- Polimorfismo
- Composição
- Tratamento de exceções
- Organização em camadas

## ♟️ Funcionalidades
- Tabuleiro de xadrez no console
- Movimentação das peças
- Validação de jogadas
- Captura de peças
- Controle de turnos
- Tratamento de jogadas inválidas

## 🛠️ Tecnologias
- C#
- .NET
- Aplicação Console
